
# Portfólio – Pablo Magalhães

Landing page estática focada em back-end Python/Django, automação e IA. Contém seções de apresentação, sobre, serviços, portfólio e contato com CTA para WhatsApp.

## Stack
- HTML + CSS (responsivo)
- JavaScript vanilla (animações simples, sliders e formulário WhatsApp)
- AOS para animações on-scroll
- Bootstrap Icons

## Estrutura
- index.html – página principal
- assets/css – estilos base e responsividade
- assets/js – interações (menu, botões, sliders, formulário)
- assets/img – logos, screenshots dos projetos

## Rodando localmente
Não há build: basta abrir `index.html` no navegador ou servir com qualquer servidor estático (ex.: `npx serve .`).

## Personalizar
- Ajuste textos e imagens diretamente em `index.html` e `assets/img`.
- Atualize número do WhatsApp em `assets/js/whatsappForm.js` e `assets/js/actionButton.js` se necessário.
- Alterações de estilo: editar `assets/css/style.css` e `assets/css/responsividade.css`.
